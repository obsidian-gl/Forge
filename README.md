# ⚡ FORGE - Terminal Swiss Army Knife ⚡

> *No internet? No problem. 9 powerful tools in your terminal.*

## 🚀 Installation

```bash
git clone https://github.com/yourusername/forge.git
cd forge
pip install -r requirements.txt
python forge.py
```

## 🛠️ Features

1. **🌧️ Matrix Rain** - Classic digital waterfall
2. **🌀 Hypnotic Spirograph** - Parametric ASCII art
3. **⌨️ Hacker Typer** - Fast-paced offline typing test
4. **📱 ASCII QR Generator** - Terminal-based QR codes
5. **🖼️ Image to ASCII Preview** - Turn images into block art
6. **🎬 Video Player (ASCII Cinema)** - Watch MP4s in your terminal
7. **🔐 Iron Vault** - Robust offline password generator
8. **📊 System Scope** - Live hardware monitoring dashboard
9. **❌ Exit Forge** - Quit the application

## 🎬 Video Player Controls
- **Space**: Play / Pause
- **Right Arrow**: Seek Forward (10s)
- **Left Arrow**: Seek Backward (10s)
- **q**: Quit Player
